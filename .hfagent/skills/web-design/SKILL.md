---
name: Web design quality
description: Use when creating or improving any web UI — ban generic AI aesthetics
---

1. Apply `frontend-design` on every create/improve web task — styling is not optional.
2. Load distinctive fonts in HTML; define CSS variables; atmospheric background.
3. Hero = brand + one headline + one line + one CTA; full-bleed; no card collage.
4. Reject and rewrite if you see cream `#faf9f5` + terracotta `#d97757`, purple gradients, Inter/Roboto-only, or unstyled CRA defaults.
5. After restyle: `npm test` + curl the live page; fix until green.
